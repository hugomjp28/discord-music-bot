# Discord Music Bot
A simple music bot for the Discord messaging platform using java.\
It utilizes JDA(Java Discord API) and the lava-player audio player library and was developped for personal use as only I can invite it to the servers I want it to be.\
Capable of playing music from various audio sources, including youtube, soundcloud, spotify and local files, aswell as capable of having queues or playlists of over 500+ songs.\
Currently being hosted on a free worker dyno in Heroku.
